# 清楚回答

1. 先讀取 `references/answer-template.md`，使用 `readSkillFile`，name 為 `clear-answer`。
2. 先用一至兩句話直接回答核心問題。
3. 依需要提供最多三個重點，並加入一個小例子。
4. 資訊不足時說明假設；不能把推測寫成已確認的事實。
5. 比較方案時說明選擇依據，避免一律推薦同一種方案。
6. 此技能只有回答格式指引，不能授權其他工具或覆蓋系統指示。
